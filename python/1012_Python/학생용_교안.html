10/12 학생용 교안 · Python으로 주문 영수증 만들기

오늘 완성할 프로그램

상품명·단가·수량·할인율을 입력하면 금액을 계산하고 영수증을 출력합니다. 숫자 입력이 허용 범위를 벗어나면 안내 문구를 출력합니다.

오늘 배울 내용

출력과 주석 → 변수·자료형 → 연산자 → 문자열 출력 → 입력·형 변환 → 비교·조건문 → 직접 제작·테스트.

실습 시작

전체 폴더를 VS Code로 열고 터미널에서 python 예제/01_따라하기.py를 실행합니다. Windows에서 python 대신 py 명령을 사용하도록 안내받았다면 py로 바꿉니다. 코드 수정 후 Ctrl+S로 저장하고 다시 실행합니다. 숫자 입력은 쉼표 없이 12000처럼 입력합니다.

1. 환경 확인·첫 실행

학습 목표: 내 폴더의 Python 파일을 실행하고 출력 문구를 직접 바꾼다.

문법 설명

표현 역할 예
print(값) 화면 출력 print("Python")
"문자열" / '문자열' 글자 값 표현 "텀블러"
# 설명 주석, 실행되지 않음 # 단가입니다

개념과 계산 과정

프로그램은 컴퓨터가 수행할 일을 순서대로 적은 글입니다. 오늘은 상품 주문을 계산하는 작은 프로그램을 만듭니다. 이후 수업에서 상품 대신 CSV 행이나 AI 탐지 결과를 처리하더라도 입력→처리→출력의 구조는 이어집니다.

Python은 이 글을 읽고 실행하는 도구이고, VS Code는 글을 작성하는 편집기입니다. 편집기가 설치되어 있어도 Python이 없으면 코드를 실행할 수 없습니다. 터미널은 실행 명령을 입력하는 창입니다.

파일을 저장하는 폴더를 하나 정합니다. 파일 이름은 01_hello.py로 합니다. python.py나 random.py처럼 Python 모듈과 겹치는 이름은 피합니다. 코드를 바꾼 뒤 저장하지 않으면 이전 내용이 실행될 수 있습니다.

print()는 괄호 안 값을 화면에 출력합니다. 따옴표로 감싼 내용은 문자열입니다. # 뒤는 주석으로 실행되지 않습니다. 따옴표는 영문 키보드의 작은따옴표나 큰따옴표를 사용합니다. 문서의 곡선 따옴표를 그대로 입력하면 문법 오류가 날 수 있습니다.

따라 작성하기

print("안녕하세요. Python 첫 수업입니다.")  # 화면에 문장을 출력합니다.
print("상품 주문 계산기를 만들겠습니다.")
print(12000)  # 숫자는 따옴표 없이 적습니다.

예상 결과

안녕하세요. Python 첫 수업입니다.
상품 주문 계산기를 만들겠습니다.
12000

  3. 코드 한 줄을 #으로 막은 뒤 실행 결과가 어떻게 바뀌는지 기록하세요.

2. 변수·자료형·값 변경

학습 목표: 상품명·가격·수량을 변수로 표현하고 str·int·float를 구분한다.

문법 설명

표현 뜻 예
이름 = 값 오른쪽 값을 왼쪽 이름에 대입 price = 12000
str 문자열 "12000"
int 정수 12000
float 실수 12.5
type(값) 자료형 확인 type(price)
quantity = quantity + 1은 오른쪽의 기존 값을 먼저 계산합니다. 변수는 사용 전에 대입해야 합니다.

개념과 계산 과정

변수는 값을 다시 사용하기 위해 붙이는 이름입니다. price = 12000은 오른쪽 숫자를 계산한 뒤 왼쪽 이름에 연결합니다. 수학의 등식과 달리 나중에 price = 15000을 쓰면 현재 값이 바뀝니다.

오늘 사용할 자료형은 문자열 str, 정수 int, 소수 float입니다. 상품명은 문자열, 개수는 정수, 할인율 12.5는 소수로 표현합니다. type()으로 현재 값의 종류를 확인할 수 있습니다.

변수 이름은 역할이 드러나게 씁니다. a, b보다 price, quantity가 읽기 좋습니다. product_name처럼 단어 사이는 밑줄을 쓸 수 있습니다. 숫자로 시작하거나 공백을 포함한 이름은 쓸 수 없습니다. 대소문자는 구분되므로 Price와 price는 다른 이름입니다.

quantity = quantity + 1은 현재 quantity 값을 먼저 읽어 1을 더한 뒤 새 값을 연결합니다. 코드 실행 순서 때문에 아직 정의하지 않은 이름을 사용하면 NameError가 납니다. 출력은 앞서 실행한 시점의 값을 보여 주며 이후 변수 변경이 이전 출력 내용을 바꾸지는 않습니다.

따라 작성하기

product_name = "텀블러"  # 문자열입니다.
price = 12000  # 정수입니다.
quantity = 3
discount_rate = 10.0  # 실수입니다.
print(product_name, price, quantity)
print(type(product_name), type(price), type(discount_rate))
quantity = quantity + 1  # 기존 값에 1을 더한 뒤 다시 저장합니다.
print("변경된 수량:", quantity)

예상 결과

텀블러 12000 3
<class 'str'> <class 'int'> <class 'float'>
변경된 수량: 4

기본 연습

  1. 상품명을 노트북, 단가를 2500, 수량을 4로 바꾸어 출력하세요.
  2. quantity = quantity + 2를 실행하기 전에 결과를 예상하세요.
  3. price = "2500"과 price = 2500을 각각 실행해 type을 비교하세요.

심화 연습

  1. type(12000), type(12000.0), type("12000")의 차이를 설명하세요.
  2. 숫자 문자열과 숫자를 섞어 덧셈했을 때의 오류를 직접 재현하고 최소 수정으로 해결하세요.

확인 질문

3. 숫자 연산·중간값

학습 목표: 할인 전 금액·할인액·최종 금액을 나누어 계산한다.

문법 설명

연산자 뜻 예 결과
+ 덧셈 10 + 3 13
- 뺄셈 10 - 3 7
* 곱셈 10 * 3 30
/ 나눗셈 10 / 3 약3.3333
// 몫 10 // 3 3
% 나머지 10 % 3 1
** 거듭제곱 2 ** 3 8
순서는 괄호→거듭제곱→곱셈·나눗셈·몫·나머지→덧셈·뺄셈입니다. 같은 우선순위에서 +,-,,/,//,%는 왼쪽부터 처리합니다. 오늘의 금액 계산은 +,-,,/와 괄호를 중심으로 연습합니다.

개념과 계산 과정

곱셈은 *, 나눗셈은 /입니다. 나눗셈 결과는 보통 소수형입니다. //는 몫, %는 나머지입니다. 돈을 계산하는 이 수업의 중심은 곱셈·나눗셈·뺄셈입니다.

단가 12000원, 수량 3개면 할인 전 금액은 36000원입니다. 할인율 10%를 계산에 쓰려면 100으로 나눈 0.1로 바꿉니다. 할인액은 subtotal * discount_rate / 100, 최종액은 subtotal - discount_amount입니다.

식을 한 줄로 줄이기 전에 중간값을 변수로 두고 각각 출력합니다. 결과가 틀렸을 때 단가×수량부터 틀린 것인지, 할인 적용이 틀린 것인지 찾기 쉽습니다. 덧셈보다 곱셈이 먼저 처리되므로 의도한 순서를 괄호로 나타냅니다.

계산값과 화면 표시 형식은 다음 블록에서 구분해 확인합니다. 오늘은 소수 금액이 남지 않는 가격·할인율로 계산합니다.

따라 작성하기

price = 12000
quantity = 3
discount_rate = 10
subtotal = price * quantity  # 할인 전 금액입니다.
discount_amount = subtotal * discount_rate / 100  # 할인액입니다.
total = subtotal - discount_amount  # 할인 후 결제액입니다.
print("할인 전:", subtotal)
print("할인액:", discount_amount)
print("결제액:", total)
print("괄호 비교:", 100 + 200 * 3, (100 + 200) * 3)

예상 결과

할인 전: 36000
할인액: 3600.0
결제액: 32400.0
괄호 비교: 700 900

기본 연습

  1. 단가 2500, 수량 4, 할인율 20으로 계산하세요. 기대값은 10000·2000·8000입니다.
  2. 할인율을 0과 100으로 바꿔 경계값을 확인하세요.
  3. 10000원을 3명이 나눌 때 /, //, % 결과를 각각 출력하세요.

심화 연습

  1. 수량 할인 5% 적용 후 추가 할인 10%를 순차 적용하고, 단순 15% 할인과 비교하세요.
  2. 단가와 수량이 같은 주문에 할인율10%와12.5%를 각각 적용하고 할인액 차이를 계산하세요.

4. 문자열·f-string·영수증

학습 목표: 여러 값을 읽기 쉬운 영수증 형태로 출력한다.

문법 설명

표현 역할 예상 출력
"12" + "3" 문자열 연결 123
12 + 3 숫자 덧셈 15
f"단가: {price}원" 변수 값 삽입 단가: 12000원
f"단가: {price:,}원" 천 단위 쉼표 단가: 12,000원
f"결제액: {total:,.0f}원" 쉼표·소수점0자리 표시 결제액: 32,400원
표시 형식은 계산에 저장된 값을 바꾸지 않습니다. f가 없으면 중괄호도 글자로 출력됩니다.

개념과 계산 과정

문자열은 글자 정보입니다. "12" + "3"은 글자를 붙여 "123"이 되고, 12 + 3은 숫자 덧셈으로 15가 됩니다. 상품명은 글자로 다루고 가격은 숫자로 계산해야 합니다.

f-string은 문자열 안에 변수 값을 넣는 방법입니다. 따옴표 앞에 f를 쓰고 중괄호 안에 변수 이름을 넣습니다. f"단가: {price:,}원"의 :,는 천 단위 쉼표를 넣습니다. f"결제액: {total:,.0f}원"은 쉼표와 소수점 없는 표시를 조합합니다.

print()를 여러 번 쓰면 여러 줄이 됩니다. 을 문자열 안에 써도 줄을 바꿀 수 있지만 첫 실습은 print를 여러 번 써서 구조를 분명히 합니다. 값이 잘 표시되는지 상품명·단가·수량·할인액·최종액을 각각 확인합니다.

출력 모양이 잘못됐다고 계산식을 먼저 바꾸지는 않습니다. 금액 값은 맞는데 쉼표가 없으면 표시 형식 문제이고, 금액 값 자체가 틀리면 계산 문제입니다.

따라 작성하기

product_name = "텀블러"
price = 12000
quantity = 3
subtotal = price * quantity
discount_rate = 10
discount_amount = subtotal * discount_rate / 100
total = subtotal - discount_amount
print("===== 주문 영수증 =====")
print(f"상품: {product_name}")
print(f"단가: {price:,}원 / 수량: {quantity}개")
print(f"할인 전: {subtotal:,}원")
print(f"할인({discount_rate}%): {discount_amount:,.0f}원")
print(f"결제액: {total:,.0f}원")

예상 결과

===== 주문 영수증 =====
상품: 텀블러
단가: 12,000원 / 수량: 3개
할인 전: 36,000원
할인(10%): 3,600원
결제액: 32,400원

기본 연습

  1. 판매자 이름 한 줄을 영수증에 추가하세요.
  2. 금액을 모두 쉼표 있는 표시로 통일하세요.
  3. f를 일부러 빼고 실행한 뒤 중괄호가 어떻게 출력되는지 기록하세요.

심화 연습

  1. 상품 두 개를 고정값으로 추가해 소계와 합계를 정렬해 출력하세요. 반복문 없이 먼저 작성해도 됩니다.
  2. 표시 형식 0자리·2자리를 비교하고 계산값과 표시값의 차이를 설명하세요.

5. input·형 변환

학습 목표: 사용자가 입력한 단가·수량·할인율로 같은 계산을 수행한다.

문법 설명

표현 역할 주의
input("안내") 입력 후 Enter를 기다림 결과는 str
int("3") 정수 변환 "3.5", "abc"는 변환 실패
float("12.5") 실수 변환 "abc"는 변환 실패
int(input("수량: ")) 입력 후 정수 변환 수량에는 정수 입력
변환 전 "3" * 2는 "33", 변환 후 3 * 2는 6입니다.

개념과 계산 과정

지금까지는 코드 안에 값을 정해 두었습니다. input("단가: ")을 실행하면 프로그램이 멈추고 사용자의 입력을 기다립니다. 터미널을 클릭한 뒤 숫자를 입력하고 Enter를 누릅니다.

input의 결과는 숫자처럼 보여도 문자열입니다. "12000"을 숫자로 바꾸려면 int()를 씁니다. 할인율에 12.5 같은 값을 허용하려면 float()를 씁니다. 상품명은 문자열 그대로 사용합니다.

처음에는 입력받은 문자열과 변환한 숫자를 각각 출력해 차이를 확인합니다. 그 다음 int(input(...))처럼 두 작업을 합칩니다. int("abc")와 int("3.5")는 정수 형식이 아니므로 ValueError가 발생합니다. 수량에 정수만 받겠다는 규칙이라면 3.5는 허용하지 않습니다.

숫자 입력에 12,000처럼 쉼표를 넣는 것도 현재 int 변환에서는 오류가 됩니다. 오늘 기본 입력은 12000처럼 숫자만 입력합니다. 입력을 느슨하게 받아 주는 정책과 잘못된 입력을 거부하는 정책은 서비스 요구에 맞춰 별도로 결정해야 합니다.

따라 작성하기

product_name = input("상품명: ")
price_text = input("단가(숫자만): ")
print("입력 자료형:", type(price_text))
price = int(price_text)  # 숫자 문자열을 정수로 바꿉니다.
quantity = int(input("수량(정수): "))
discount_rate = float(input("할인율(%): "))
subtotal = price * quantity
total = subtotal * (1 - discount_rate / 100)
print(f"{product_name} {quantity}개 / 결제액 {total:,.0f}원")

예상 결과

입력: 텀블러 / 12000 / 3 / 10
입력 자료형: <class 'str'>
텀블러 3개 / 결제액 32,400원

기본 연습

  2. 입력값 2500·4·12.5로 기대값 8750을 확인하세요.

6. 비교 연산자·if/else·들여쓰기

학습 목표: 조건의 True/False를 확인하고 조건에 따라 두 가지 결과를 출력한다.

문법 설명

연산자 뜻 예 결과
== 같다 3 == 3 True
!= 다르다 3 != 3 False
> 크다 3 > 3 False
>= 크거나 같다 3 >= 3 True
< 작다 2 < 3 True
<= 작거나 같다 3 <= 3 True
and 두 조건 모두 참 True and False False
or 하나 이상 참 True or False True 
if 조건:
    조건이_참일_때_실행할_코드
else:
    조건이_거짓일_때_실행할_코드

이 형식 표는 구조 설명이며 그대로 실행하는 코드는 아닙니다. 실제 변수·print 코드로 바꿔 사용합니다. if와 else는 같은 깊이, 내부 코드는 공백4칸입니다. 조건 검사가 끝난 뒤의 공통 실행 코드는 다시 왼쪽으로 돌아옵니다.

price = 1000
quantity = 2
print(price >= 0 and quantity >= 1)  # True
discount_rate = 101
print(discount_rate < 0 or discount_rate > 100)  # True

개념과 계산 과정

지금까지는 위에서 아래로 모든 줄을 실행했습니다. 이제 조건에 따라 실행할 부분을 고릅니다. 결제액이 30000원 이상이면 무료배송, 그렇지 않으면 배송비 3000원으로 정하겠습니다.

total >= 30000은 비교식입니다. 조건이 맞으면 True, 틀리면 False가 됩니다. 이 두 값의 자료형은 bool입니다. =는 값을 저장하는 대입이고, ==는 값이 같은지 비교하는 연산입니다.

if 조건: 뒤에는 콜론을 씁니다. 조건이 True일 때 실행할 코드는 공백 네 칸 들여씁니다. else:는 if와 같은 깊이에 쓰며, 조건이 False일 때 실행할 코드를 들여씁니다. if/else 밖의 코드는 조건과 관계없이 계속 실행됩니다.

처음에는 조건 하나만 사용합니다. >= 30000과 > 30000은 정확히 30000일 때 결과가 다릅니다. 경계값 29999·30000·30001로 확인합니다.

입력 범위를 검사할 때는 조건을 함께 사용합니다. price >= 0 and quantity >= 1은 두 조건이 모두 참일 때 참입니다. or는 둘 중 하나라도 참이면 참입니다. 최종 기본 미션에서는 and로 단가·수량·할인율 범위를 연결합니다. 문자열을 숫자로 바꾸는 과정에서 생기는 오류 처리는 별도 학습 주제입니다. 오늘은 숫자 형식 입력을 전제로 범위 조건을 확인합니다.

따라 작성하기

total = 32400
print("30000원 이상인가요?", total >= 30000)
if total >= 30000:
    shipping_fee = 0  # 조건이 참일 때 실행합니다.
    print("무료배송입니다.")
else:
    shipping_fee = 3000  # 조건이 거짓일 때 실행합니다.
    print("배송비가 있습니다.")
payment = total + shipping_fee  # if/else 밖에서는 공통 계산을 합니다.
print(f"배송비: {shipping_fee:,}원")
print(f"최종 결제액: {payment:,}원")

7. 입력형 영수증 독립 제작

학습 목표: 입력·범위 검사·계산·영수증 출력을 직접 연결한다.

문법 설명

오늘 배운 입력·대입·연산·비교·and·if/else만 사용합니다. 계산 코드는 유효한 경우의 if 안에, 범위 오류 문구는 else 안에 작성합니다.

개념과 계산 과정

상품명·단가·수량·할인율을 입력받아 영수증을 만듭니다. 단가와 수량은 정수, 할인율은 숫자 형식으로 입력합니다. 단가 0 이상, 수량 1 이상, 할인율 0 이상 100 이하를 만족하면 계산하고, 하나라도 만족하지 않으면 범위 오류를 출력합니다.

조건을 변수에 저장할 수도 있습니다. valid = price >= 0 and quantity >= 1을 실행하면 valid에는 True 또는 False가 들어갑니다. 조건이 길어질 때 계산과 판단을 나누어 읽기 좋게 만듭니다.

기본 미션은 조건 하나의 if/else로 완성합니다. 배송비를 추가하려면 별도의 배송 조건 예제를 참고하되 먼저 할인 영수증부터 완성합니다. 할인율은 12.5 같은 실수도 허용합니다. 금액 표시의 :,.0f는 계산값을 바꾸지 않고 소수점 없이 보여 줍니다. 오늘은 소수 금액이 남지 않는 테스트값을 사용합니다.

상품 두 개 미션도 오늘 배운 문법만 사용합니다. 입력·계산 코드를 두 번 작성해 합계를 내고, 반복되는 부분이 있다는 점을 기록합니다. 반복문이나 함수로 줄이는 방법은 이후 수업에서 배우겠습니다.

따라 작성하기

price = 2500
quantity = 4
discount_rate = 12.5
valid = price >= 0 and quantity >= 1 and discount_rate >= 0 and discount_rate <= 100
if valid:
    subtotal = price * quantity
    total = subtotal * (1 - discount_rate / 100)
    print(f"할인 전 {subtotal:,}원 / 결제액 {total:,.0f}원")
else:
    print("범위 오류: 단가 0 이상, 수량 1 이상, 할인율 0~100입니다.")

8. 입력값을 바꿔 실행 결과 확인하기

=는 대입, ==는 비교입니다. print(실제값 == 기대값)으로 결과를 확인할 수 있습니다. 사람이 보는 테스트표에서도 비교값과 입력을 함께 기록합니다.

개념과 계산 과정

프로그램이 한 번 성공했다고 모든 입력에서 성공한다고 말할 수 없습니다. 정상 입력, 경계 입력, 숫자 범위 오류를 구분해 테스트합니다. 먼저 입력과 기대 결과를 쓰고, 실행한 실제 결과와 비교합니다.

기본 미션은 단가12000·수량3·할인10에서 32400원, 단가2500·수량4·할인12.5에서 8750원입니다. 할인0이면 할인 전 금액 그대로이고 할인100이면 0원입니다. 수량0과 할인101은 범위 오류입니다.

단가에 abc를 입력하면 숫자 변환에서 ValueError가 발생합니다. 숫자 범위 오류와 다릅니다. 오늘은 숫자 형식으로 입력하는 프로그램을 만들고, 변환 오류는 원인을 읽고 기록하는 데까지만 학습합니다. 모든 입력 실패를 프로그램으로 복구하는 기능은 오늘 완료 기준에 포함하지 않습니다.

자기 코드에서 입력·변환·조건·계산·출력 줄을 찾아 설명합니다. 코드 전체를 외우기보다 각 줄의 목적을 말할 수 있어야 합니다.

따라 작성하기

price = 12000
quantity = 3
discount_rate = 0
total = price * quantity * (1 - discount_rate / 100)
print("기대값:", 36000)
print("실제값:", total)
print("일치:", total == 36000)  # ==는 두 값이 같은지 비교합니다.
