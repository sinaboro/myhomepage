### 심화 미션 안내 — 상품 두 개와 배송비 계산하기

**할 일:** 상품 두 개의 할인 후 금액을 합친 뒤 배송비를 결정합니다. 기본 미션을 완료한 학생 또는 같은 기능을 독립적으로 작성할 수 있는 학생이 선택합니다.

#### 1. 시작 파일과 실행
`예제/심화_미션.py`를 `예제/my_order.py`로 복사하여 작성합니다. 시작 파일에는 작성 순서만 있으며 완성 코드가 아닙니다.
```text
python 예제/my_order.py
```

#### 2. 작성할 기능
1. 상품1의 이름·단가·수량·할인율을 입력받습니다.
2. 상품2도 같은 네 값을 입력받습니다. name1/price1/quantity1/rate1과 name2/price2/quantity2/rate2처럼 구분합니다.
3. 두 상품 모두 기본 미션의 숫자 범위 규칙을 검사합니다.
4. 각 상품의 할인 후 금액을 계산하고 합칩니다.
5. **할인 후 합계가30000원 이상이면 배송비0원, 미만이면3000원**을 적용합니다.
6. 상품별 할인 후 금액·합계·배송비·최종 결제액을 출력합니다.
7. 어느 상품이든 숫자 범위가 잘못되면 범위 오류를 안내하고 최종 결제액을 출력하지 않습니다.

같은 입력 코드를 두 번 작성해도 됩니다. 함수·반복문을 사용해야 하는 과제가 아닙니다.

#### 3. 입력과 출력 예
|상품|이름|단가|수량|할인율|상품별 할인 후 금액|
|---|---|---:|---:|---:|---:|
|1|텀블러|12000|3|10|32400|
|2|노트|2500|4|12.5|8750|
프로그램을 실행하고 위 표의 값을 상품1 네 번, 상품2 네 번, 총8번에 걸쳐 입력·Enter 합니다.
```text
텀블러: 32,400원 / 노트: 8,750원
할인 후 합계: 41,150원
배송비: 0원
최종 결제액: 41,150원
```

#### 4. 정책 비교 추가 과제
정상 주문에서 할인 전 합계31000원, 두 상품 할인율10%를 적용해 보세요. 예: 상품1 단가15000·수량1, 상품2 단가16000·수량1입니다.
- 할인 후 합계27900원 기준: 배송3000원, 최종30900원.
- 할인 전 합계31000원 기준으로 조건을 바꾼 경우: 배송0원, 최종27900원.
원본 my_order.py는 할인 후 기준으로 유지합니다. 비교용 복사 파일 my_order_before.py에서 조건만 바꿔 두 정책의 차이를 기록하세요.

#### 5. 완료 기준
두 상품의 입력·범위 검사·할인·합계·배송 계산이 동작하고, 아래 심화4개 입력의 결과를 기록합니다. 추가 정책 비교는 별도로 작성합니다.
참고 정답은 여러 단순 if/else를 순서대로 사용합니다. 오류 주문의 order_total=-1은 실제 결제액이 아니라 ‘유효하지 않은 주문’ 표시입니다. 마지막 출력은 order_total>=0일 때만 수행합니다. 다른 구조로 같은 요구사항을 충족해도 됩니다.
