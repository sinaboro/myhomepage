### 기본 미션 안내 — 상품 한 개의 영수증 만들기

**할 일:** 설명을 따라 실행했던 코드를 연결하여, 사용자가 상품 정보를 입력하면 할인 금액이 나오는 프로그램을 직접 작성합니다.

#### 1. 어느 파일에서 작성하나요?
`예제/기본_미션.py`를 복사하고 이름을 `my_receipt.py`로 바꿉니다. 이 파일은 작업 순서가 적힌 시작 파일입니다. 처음 실행하면 안내 문구만 나오며, 아직 주문 계산 기능은 없습니다. 주석(`#`) 아래에 실행할 코드를 직접 작성하세요. 기존 안내 print는 삭제해도 됩니다.

#### 2. 무엇을 입력받나요?
|순서|정보|변수 이름|자료형|입력 예|
|---|---|---|---|---|
|1|상품명|product_name|str|텀블러|
|2|단가|price|int|12000|
|3|수량|quantity|int|3|
|4|할인율(%)|discount_rate|float|10 또는12.5|
가격은 쉼표 없이 입력하고, 할인율에 % 기호를 쓰지 않습니다.

#### 3. 어떤 순서로 작성하나요?
1. input으로 상품명을 받습니다.
2. 단가·수량은 int(input(...)), 할인율은 float(input(...))로 받습니다.
3. 단가0 이상·수량1 이상·할인율0~100을 비교식과 and로 검사합니다.
4. 조건이 참인 if 안에서 할인 전 금액→할인액→결제액을 계산합니다.
5. 같은 if 안에서 상품명과 금액을 영수증으로 출력합니다.
6. else 안에서는 범위 오류 안내만 출력합니다. 잘못된 숫자 범위로는 결제액을 출력하지 않습니다.

계산식은 다음과 같습니다.
```text
할인 전 금액 = 단가 × 수량
할인액 = 할인 전 금액 × 할인율 ÷ 100
결제액 = 할인 전 금액 − 할인액
```
숫자로 바꿀 수 없는 abc 입력을 안내문으로 처리하는 기능은 이 미션에서 작성하지 않습니다.

#### 4. 어떻게 실행하나요?
VS Code에서 전체 10/12 폴더를 열고 터미널에 입력합니다. my_receipt.py를 예제 폴더에 저장했다면 아래 명령을 사용합니다.
```text
python 예제/my_receipt.py
```
명령 뒤에 네 값을 한꺼번에 붙이는 것이 아닙니다. 프로그램의 질문이 나올 때마다 한 값을 입력하고 Enter를 누릅니다.
```text
상품명: 텀블러       ← 텀블러 입력 후 Enter
단가: 12000         ← 12000 입력 후 Enter
수량: 3             ← 3 입력 후 Enter
할인율: 10          ← 10 입력 후 Enter
```
위의 화살표와 설명은 입력하지 않습니다. 안내 문구는 자신의 코드에서 다르게 작성해도 됩니다.

#### 5. 어느 결과가 나와야 하나요?
```text
상품: 텀블러
할인 전: 36,000원
할인액: 3,600원
결제액: 32,400원
```
문구·장식은 달라도 됩니다. 정보와 계산값이 맞아야 합니다.

#### 6. 언제 완료인가요?
- 네 값을 직접 입력받는다.
- 정상 주문의 할인 전 금액·할인액·결제액을 출력한다.
- 수량0 또는 할인101 같은 범위 오류에는 안내를 출력한다.
- 아래 ‘실행 결과 확인하기’의 기본6개 입력을 모두 확인한다.
- 입력·변환·조건·계산·출력 줄을 설명할 수 있다.

막히면 5번 따라하기(입력), 6번 따라하기(조건), 7번 따라하기(범위 검사)를 참고하세요. 예제와 정답을 실행한 것만으로 자기 미션이 완성되는 것은 아닙니다.
