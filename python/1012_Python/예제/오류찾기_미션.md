# 오류 찾기 6문제
각 코드를 별도 파일에서 실행합니다. 오류 종류·문제 줄·수정 코드를 기록하세요.
1. `print("안녕하세요)`
2. `price = 12000` 다음 줄에 `print(Price)`
3. `price = "12000"` 다음 줄에 `print(price + 1000)`
4. `quantity = int("3.5")`
5. `total = 36000 * 10` (의도: 10% 할인액)
6. `total = 32400` 다음 줄에 `print("결제액: {total}")`
1~4는 실행 오류, 5~6은 실행돼도 의도와 다른 결과입니다.
