실행 결과 확인하기 — 직접 만든 프로그램을 다시 실행해 보세요

이 표는 무엇을 하는 활동인가요?

내 프로그램에 여러 입력을 넣어 계산과 조건이 맞는지 확인하는 기록지입니다. 시험 문제가 아니며 자동으로 실행되는 표도 아닙니다. 표의 한 행은 ‘프로그램을 한 번 실행할 때 넣을 값’입니다.

  • 기대 결과: 계산·입력 규칙에 따라 나와야 하는 정답입니다. 실행 전에 읽습니다.
  • 실제 결과: 내 프로그램 화면에 나온 결제액 또는 안내 문구입니다. 직접 적습니다.
  • 일치 여부: 기대 결과와 같으면 ✓, 다르면 ✗를 적습니다. HTML 표는 읽는 자료입니다. 기록은 학생용_실습지.md를 복사해 수정하거나 인쇄한 실습지·노트에 적습니다.

기본 미션: T1을 함께 해보기

  1. 내 코드 예제/my_receipt.py를 저장합니다.
  2. 터미널에서 python 예제/my_receipt.py를 실행합니다.
  3. 상품명에 텀블러, 단가에12000, 수량에3, 할인율에10을 질문 순서대로 한 개씩 입력하고 Enter 합니다.
  4. 화면의 결제액을 읽습니다. 32400원이면 ‘실제 결과’에32400원, ‘일치 여부’에✓를 씁니다.
  5. 다른 결과면 할인 전36000원·할인액3600원부터 확인하고 코드를 수정합니다. 저장하고 같은 T1 입력으로 다시 실행합니다.
  6. T1이 맞으면 프로그램을 다시 실행하여 T2의 값을 입력합니다. 프로그램 안에서6개 행을 한꺼번에 처리할 필요는 없습니다. 반복문을 작성하지 않아도 됩니다.

작성 예시 — 기록 방법만 보여 주는 행

번호 넣은 값 기대 결과 실제 결과 일치 여부
T1 예시 텀블러 / 12000 / 3 / 10 32400원 32400원 ✓
이 예시를 보고 아래 빈칸에는 자신이 실제로 실행한 결과를 기록합니다.

기본 미션 확인표 — my_receipt.py에서6번 실행

번호 상품명 단가 수량 할인율 기대 결과 실제 결과 일치 여부
T1 텀블러 12000 3 10 결제32400원
T2 노트 2500 4 12.5 결제8750원
T3 텀블러 12000 3 0 결제36000원
T4 텀블러 12000 3 100 결제0원
T5 텀블러 12000 0 10 범위 오류 안내, 결제액 없음
T6 텀블러 12000 3 101 범위 오류 안내, 결제액 없음
T5·T6은 ‘범위 오류 안내가 나오고 결제액이 출력되지 않음’이 기대 결과입니다. 문구는 달라도 뜻이 같으면 ✓입니다. 이 두 행에서 오류 안내가 나오는 것이 프로그램의 올바른 동작입니다.

심화 미션 확인표 — my_order.py에서4번 실행

각 상품의 이름은 A와B로 입력합니다. ‘단가/수량/할인율’의 세 값을 각각 입력합니다. |번호|상품1 단가/수량/할인율|상품2 단가/수량/할인율|기대 결과|실제 결과|일치 여부| |---|---|---|---|---|---| |S1|12000 / 3 / 10|2500 / 4 / 12.5|합계41150, 배송0, 최종41150원||| |S2|10000 / 1 / 0|10000 / 1 / 0|합계20000, 배송3000, 최종23000원||| |S3|15000 / 1 / 0|15000 / 1 / 0|합계30000, 배송0, 최종30000원||| |S4|1000 / 0 / 0|1000 / 1 / 0|범위 오류 안내, 최종 결제액 출력 없음||| 기본 경로를 선택한 학생은 T1~T6을 기록합니다. 심화 경로는 먼저 기본 동작을 확인한 뒤 S1~S4도 기록합니다.

결과가 다르면 무엇을 하나요?

숫자가 다르면 단가·수량→할인 전 금액→할인액→결제액 순서로 확인합니다. 배송만 다르면 >=30000 조건을 확인합니다. 범위 오류에도 결제액이 나오면 계산·출력 줄이 유효한 경우에만 실행되는지 확인합니다. 수정 후 실패했던 입력을 다시 넣고 결과를 기록합니다.

제출

자기 코드 파일, 작성한 결과 확인표, 직접 수정한 두 줄과 설명을 제출합니다. 예제나 정답을 그대로 실행한 기록만 제출하지 않습니다.
